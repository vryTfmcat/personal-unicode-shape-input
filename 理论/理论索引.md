# 理论索引

这里保存直接服务于个人 Unicode 输入法的研究框架，而不是一般性的符号学资料库。每页均把冷库构想、可核验参考和可实现规则分开。

## 研究地图

| 理论页 | 回答的问题 | 对当前项目的产出 |
| --- | --- | --- |
| [[音形键位分配]] | 前两键的私人联想与后两键的视觉形态怎样协同？ | 四码容量、短码边界、形态标签和试打方法 |
| [[人机交互与输入法]] | 如何让个人码表可学习、可纠错、可评估？ | 任务流、输入日志和可用性测试指标 |
| [[语义图形]] | 字形如何成为可描述、可检索的线索？ | `shape_tags` 词表与字形特征实验 |
| [[图形语]] | 组合符号如何表达含义而不失去可输入性？ | 字符组合、边界和候选呈现规则 |
| [[字符纹样研究]] | 如何研究个人符号的视觉家族与记忆关联？ | 纹样标签、样本集和混淆对照 |
| [[符号学与个人语义]] | 私人联想如何保留，又如何避免把联想当公共定义？ | `mnemonic`、`note`、来源与语义状态字段 |
| [[布利斯符号 Blissymbols]] | 成熟图形符号系统能提供哪些借鉴和限制？ | 构形、词汇和可访问性研究问题 |

## 实施顺序

1. 先确认字符候选，建立最少一批实体页。
2. 用 [[语义图形]] 的标签词表填写后两码的字形依据。
3. 用 [[人机交互与输入法]] 的指标比较“能记住”和“实际能快速输入”是否一致。
4. 只有当某个符号组合稳定复用时，才进入 [[图形语]] 的组合规则研究。

## 证据边界

- 冷库页面是个人构想与来源线索，不自动构成学术事实。
- 外部资料只在其能指导项目决策时引用；无法核验的数字、泛化结论和工具承诺不进入设计规则。
- 理论页不会替代 `实体/` 中的具体字符定义或 Rime 配置。
