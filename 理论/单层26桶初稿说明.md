## 第一轮结果

范围56,347个非统一／兼容汉字记录，与上一轮语料一致；仍包括〇、部首、笔画、带圈文字等。50,214个有可观测字形并已分桶，6,133个无可观测字形，保留待处理。每字符只有一个主归属。

完整语料容量区间是每桶1,734～2,600字。考虑目前可观测语料的均值，首轮使用1,734～2,317的较紧区间，给后续补字留下空间。实际主桶范围1,734～2,316字，26桶都非空。

14,183个边界字符获得至多两个补充入口，别名不计容量。3,256个主归属与最终中心的最近桶标签不同；其中可能存在近距离或等距离情况，不代表全部属于肉眼错误。补充入口依据距离阈值自动生成，尚未逐字确认。

初步形近诊断抽取512个字符，对每字检索同一特征空间中最接近的5个其他字符，共2,560对：78.32%的近邻在同一主桶；计入双方补充入口后，93.91%的近邻共享至少一个入口。这是机器特征空间的局部一致性指标，不能当作真人判断的准确率。容量分配后的平均平方距离为0.84299，直接分到最近最终中心的平均距离为0.83755，前者高约0.65%。这个比较使用相同最终中心，不是与独立训练的无约束聚类比较。

普通更新已完整重跑验证：50,214个旧主归属及其别名记录逐项一致，聚类模型未改变。新增／补齐字形只能进入仍有容量的桶；没有容量时排队，不搬动已冻结字符。新增分配、满容量等待也有回归测试。

## 方法和需要核对的地方

按锁定参考字体48px重新渲染字形，裁去空白，等比例居中放入24×24画布。实际宽高比保留，不把字符强行拉成方形。整体尺寸不参与聚类，避免尺寸先把同一形族拆散；尺寸资料继续用于后续固定规则。

轮廓用32维PCA压缩，保留约60.39%的像素方差；同时加入宽高比、墨迹密度、闭孔、构件、对称性、长直干、角部墨迹和斜向性等10项结构特征。细小点、钩尾可能在这一分辨率下损失，仍需人工核对。

采用26簇迭代与贪心容量修复，16轮后保存最低误差的可行结果。该方法保证本轮容量约束成立，不宣称精确最小费用流或全局最优。聚类只读取字形特征，不读取Unicode区块、名称或数字／字母身份。

字母a～z沿中心相似路径暂排，是桶标签；尚未提炼各桶的可背诵字义，也没有验证键盘物理位置相邻。现阶段相似圆形分布在t、u等近邻桶，C与Ϲ落在不同桶，说明还需要检查比例与轮廓权重。后续调整应有版本并明确展示迁移字符，不能在普通更新中悄悄洗牌。

## 使用和稳定性

```powershell
# 首次运行建桶；以后普通运行只增补，保留冻结主归属和别名
python -X utf8 工具/balanced_shape_buckets.py
python -X utf8 工具/validate_shape_buckets.py
python -X utf8 工具/test_balanced_shape_buckets.py

# 仅在明确要重分全部桶时使用；旧版本仍保留
python -X utf8 工具/balanced_shape_buckets.py --rebuild
```

分桶读取上一轮完整实验的锁定字形缓存及参考字体。更换字体必须先重新生成完整字形实验。模型、主归属、别名、源码与来源信息按运行版本保存，最新分桶指针位于规则库/单层分桶/最新分桶.json。有效码本不读取这些初稿，核对通过后再另行决定编码和发布。
