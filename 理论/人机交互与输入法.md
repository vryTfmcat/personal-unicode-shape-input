# 人机交互与输入法

## 冷库起点

- [[90_旧库冷归档/Unicode原库_迁移前快照/茂ܜ/人机协同/人机协同|人机协同]]把输入法、键盘操作与身体协同并列为研究线索。
- [[90_旧库冷归档/Unicode原库_迁移前快照/茂ܜ/人机协同/输入法/Unicode输入法初始demo|Unicode输入法初始demo]]提出了“前两码音联想、后两码图形匹配”的个人四码方案。

## 可采用的原则

1. 先从真实输入任务出发：记录“要输入什么、在哪里输入、是否需要候选、是否输入成功”，而不是先追求覆盖全部 Unicode。
2. 人能记住的码不等于能快速输入的码。首版应分别测量首次成功、隔日回忆、冲突处理和完整任务耗时。
3. 码表必须可恢复：每次改码保留旧码、改动原因和使用状态；未稳定的条目不直接覆盖日常输入习惯。
4. 候选界面服务于纠错。唯一候选自动上屏；重码展示有限候选，并让使用者能从候选页回到对应实体页。

## 项目规则

- `mnemonic` 记录私人读音或联想，不宣称为字符的通用名称。
- `shape_tags` 描述可观察的形态，不使用只有事后才懂的模糊标签。
- 每次试用至少保留：目标字符、输入码、是否成功、是否查看候选、耗时或主观负担。

## 参考

- ISO 9241-210:2019, *Human-centred design for interactive systems*：以使用情境、用户需求、评估和迭代作为交互设计的基本循环。
- [ISO 9241-210 条目](https://www.iso.org/standard/77520.html)：在线页面可能受访问限制，标准编号和标题是稳定检索入口。
