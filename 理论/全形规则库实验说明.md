## 试验范围和结果

六类策略：轮廓优先、拓扑优先、比例优先、主干与附件、可量化特征分档、视觉聚类。每类各有粗分／标准／细分版本，共18套。分类使用实际字形的墨迹、闭孔、构件、对称、长直干、比例和缩略图，不使用数字、字母、Unicode名称或区块身份分码。

范围是项目现有 `han` 标记之外的56,347个字符；统一汉字和兼容汉字排除，〇、部首、笔画等仍保留。18套策略各有全量记录，共1,014,246条。50,214个字符产生机器四码；6,133个没有可观测字形，其中3,829个缺少字体映射，2,304个无可用墨迹或渲染不支持。未观测记录的编码为空，不能视为完成字形分类。

第四位全表冻结，特别是 WASD 上下左右、JK/NM 四角、ZXCV 微小／小／中／大。各策略使用完全相同的观测对象和末位集合。第三位保留多种对象入口，同一字符可有多个码。前三位的空键和同码均允许存在。

默认综合权重为均衡40%、易记代理40%、视觉代理20%。当前前四名：

暂优路线可概括为“整体轮廓 → 构件／闭孔状态 → 比例或局部对象 → 冻结的尺寸或方位”。它有142个实际前三码组，最大组占字符均分权重的11.53%；尚未做到均匀填满26个字母。前三位每个字母的具体意义见完整报告和查询页，不在这里省略含义列举候选码。

## 结论的限度

易记分是人为语义／字母联想先验和复杂度的代理，尚未做真人记忆测试；修改先验或综合权重可能改变排名。视觉分是全字描述的分组方差，局部对象码会被低估。暂优仅限于这18种策略、目前参考字体和权重，不能称为所有可能规则的最优。

42个已确认样本中23个至少命中一个原末位入口，命中率54.76%。该指标只表示末位集合有交集，不是完整码正确率，也不是所有已确认别名被保留的比例。原来的人工确认结果没有被改写。试验中的固定尺寸阈值和启发式局部对象仍需修正。

`C、Ϲ` 曾被图像规则误判为钩，已通过左右开口与上下对称的形状条件修正为曲弧；增加了回归检查。末端钩估计仍属低置信度。第一位钩弯与第三位钩尾等跨位相关功能尚未完全自动审计，不因评分领先而视为解决了信息重复。后续核对应集中检查这些问题，并在相同全量语料上复算，而非靠增加单字例外掩盖问题。

## 复算与追溯

使用项目的Python环境（需要NumPy、Pillow）：

```powershell
python -X utf8 工具/shape_strategy_lab.py
python -X utf8 工具/shape_strategy_lab.py --weights 0.6 0.2 0.2
python -X utf8 工具/inspect_shape_lab.py --validate
python -X utf8 工具/inspect_shape_lab.py --chars '○◯Oo〇0CϹJj'
python -X utf8 工具/inspect_shape_lab.py --chars '○◯0' --strategy topology-standard
python -X utf8 工具/prepare_shape_lab_review.py
```

`--limit` 只用于冒烟检查，不能作为全量验收。普通复算复用已锁定的字形缓存；`--refresh` 重新渲染。策略算法和分类阈值在 `工具/shape_lab_rules.py` 中维护；规则策略库JSON是生成的说明，不是任意改算法的执行语言。改变策略应编辑源代码，保留逐字符核对并重新评估。字母含义不能仅修改说明JSON，否则会与实际编码不一致。

每次实验保存源代码与第四位布局快照、SHA-256、字体映射及文件校验清单、聚类原型、共同观测对象和18套全量编码。补充字体来源及许可证位于规则库/字体；Egyptology Extended 使用 CeCILL v2.1，作者归属详见报告及 ATTRIBUTION-Egyptology.txt。

已通过：几何形状／连通性、圆弧误判、字体Last Resort拒绝、缺字不补造末位、多码去重、固定末位、评分权重、聚类确定性、原批次键义审计、四位标注、全量身份与编码完整性。交互页的排名、零权重提示、字符／码位／前缀查询及待补字形队列通过脚本运行检查；未将其等同于真人视觉核验。
