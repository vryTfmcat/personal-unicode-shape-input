## D 位方向四条铁律（v6.2 终局定稿）

1. **有离散附标，看附标相对主体的位置**（上下两侧都有取 `V`）。
2. **箭尖、尾巴和枝头，看向哪边**（`PF` 弧弯箭开放全部 8 向 `W/A/S/D/J/K/N/M`）。
3. **开口弧、折角和单叉，看弧背、尖角或分叉所在侧**（开口反方向，与墨迹重心同向）。
4. **复杂无开口且无附标，先看对称、双线、斜倾，再看哪边更重**（居中均衡取 `F`）。
