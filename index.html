1. 功能设计重点

  • 三层 + 保留 + 英文直通：几何 G、拟像 T、附标 X、远期汉字 Z，右 Shift 切换英文直通。
  • 双顺序无缝投影：BCDA（先规则后视觉）与 ABCD（先视觉/大类后规则）同源切换。
  • 半码 G8 聚合与平铺：1–3 位支持按全码桶聚合代表字（降序排列、显示补全后缀与字数），也支持平铺全部。
  • 双态候选窗：收起态 ≤9 项数字直选；Ctrl+Shift+E 切换全铺网格，保持高亮焦点。
  • 反查与引导演示：支持字符、码点、四码前缀与中文关键词反查，并一键在虚拟键盘亮灯引导按键。

2. UI 与视觉风格

  • 字形标本盒气质：固定卡片外框与低饱和角标，字形永远是视觉核心。
  • 深色墨绿 / 浅纸色双主题：白底黑字雪碧图在深色下自动反色增透，保证细笔画锐利可见。
  • 不可见与附标显形：附标自动加虚线圆底座 ◌ 预览，上屏提交原始码点。
  • 三色状态 + 文字双提示：绿（几何）、琥珀（拟像）、蓝（附标）与文字标签同步呈现，不靠猜色。
