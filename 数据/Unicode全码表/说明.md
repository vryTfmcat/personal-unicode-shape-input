# Unicode 17 全字符编码说明

## 结果

- 来源：[[../unicode全字符/Unicode全字符表|Unicode全字符表]] 中的 336 个主区块笔记，不重复载入 `官方结构` 镜像。
- 字符：159,345 个 Unicode 17 已分配字符。
- 前缀页：380 个。
- 唯一四码：49,699 个；每个四码最多 5 个候选。
- Rime 另保留 `𓆟 = jj` 与 `༳ = my` 两个短码，所以最终词典共有 49,701 个唯一编码。

## 前两码

优先取 Unicode 英文区块名主要单词的首字母，例如 Kirat Rai 使用 `kr`。一个前缀容量为 676 个后缀、每个后缀至多 5 个候选；大型区块超过容量或需要更好翻页时，会继续分配相关或空闲的两字母前缀。为了保持记忆边界，一个机器生成的前缀页只承载一个 Unicode 区块，不拿小区块页面的剩余容量混装大区块字符。

既有人工码表与锚点优先级最高，不因全量分配而改写：埃及象形文字、奥里亚、亚美尼亚、数学符号 B、楔形文字、泰米尔及常用字符仍保留原码。

## 后两码

可从 Unicode 名称明确识别形态的符号，优先套用项目的骨架与状态键。文字、表意字符等无法仅凭名称可靠判断字形的字符，使用稳定、均衡的机器占位后缀，以满足全量可输入和每码最多 5 个候选。占位码是第一轮工作码，不代表已经人工确认视觉分类；可在本地编辑器里拖动、改码和补充各页规则。

## 生成文件

- `unicode-17-全字符编码.tsv`：逐字符完整码表。
- `unicode-17-前缀页.tsv`：前缀页、区块归属、数量和页面说明。

重新生成使用 `工具/build_all_unicode_keymap.py`；生成编辑器数据使用 `工具/build_key_editor_data.py`；生成 Rime 词典使用 `工具/build_catalog.py --write`。
