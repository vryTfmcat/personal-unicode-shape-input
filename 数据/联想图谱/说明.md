# 个人联想图谱

`association-graph.json` 保存 26 个字母感觉、676 个独立双字母感受、精选字符、中文概念、主题、关系和已启用联想码。

## 初始内容

- 精选字符：2,000 个。
- 机器简单建议：500 条，每字符最多一条。
- `v`：危险感。
- `r`：yuan → ruan，以及圆满、完美。
- `○`：完整、完美。

机器建议状态为 `suggested`，只提供直观形态或少量常见象征。它已经显示在图谱中，但不会占用双字母，也不会导出 Rime。确认或修改后才成为个人语义。

联想码为 `ABCD`：`AB` 是一个独立双字母感受，`CD` 默认沿用字符形码。图谱联想和单字符别名数量不限；每个精确四码最多 5 个候选。若启用后会超过上限，编辑器拒绝启用，但保留原图谱关系。

主文件由本地编辑器直接原子保存。自动快照位于忽略 Git 的 `备份/`；稳定历史由本项目 Git 管理。
