区块后两位是确定性的局部形族排序与均衡序位，均标为机器暂有码。每区块局部键义仍待人工核定。全形的名称提示、字体依据与旧人工字形参考也均作为待核对建议，未宣布为最终分类。逐字确认由用户进行；首批入口覆盖几何图形、巽他标点和基本拉丁。

## 验证结果

- 原有 14 个 Python 回归检查及原搜索 Node 检查通过；新增独立码本、原生 Rime、发布事务检查通过。
- 数据检查验证三套编码互不覆盖、区块全量唯一、普通重建保留人工覆盖、全形细分空值、中文可靠码覆盖与异常拒绝。
- API 检查验证两窗口同版本并发写入返回一个 200、一个 409；IPA 和备注持久化、快照、发布版本校验正常。
- Node 行为检查覆盖全部来源合并与排序、旧浏览器草稿幂等迁移、前缀改名、Shift 单按／组合／重复／失焦。
- 本机 Rime 核心在隔离目录验证七种非空模式组合 × 四种中文／扩展设置，并逐条比较真实候选顺序及来源；每次 252 组查询。额外启用收藏夹具验证收藏＋全形、收藏＋区块、收藏＋中文的合并，测试夹具未写入用户码本。
- 原生键盘检查验证左 Shift 循环、组合大写不切模式、长按只切一次、输入中切换保留编码、右 Shift 中英文、空格／数字选字、全部候选翻页、重启恢复模式和中文设置。
- 浏览器检查验证窄窗口与桌面布局、三种工作区、全形两码／多余第三码、中文开关、收藏图谱、备注写入与恢复。局部规则预览显示实际受影响字符，应用前不写项目；前缀调整也需先预览。
- 发布事务检查验证保留既有配置、独立临时构建、备份和失败恢复。

## 本机发布

首次发布备份：`原型/rime/备份/unicode-modes-20261006-001518-264397/`。其中 `manifest.json` 记录 `weaselRedeployed: true`、部署前隔离验证、部署后本机编译词典验证及全部同步源文件校验值。最终生成源文件与 Rime 用户目录中的文件一致。小狼毫服务持续运行。

部署后验证读取本机实际编译词典，在临时会话中检查真实 Rime 候选，不向用户应用写入测试字符。首次使用需从小狼毫方案菜单选择 **Unicode 三模式**；后续模式与中文开关在该方案内保存。

全形后两位的正式规则及逐字字形复核留给后续核对；本版提供试验笔记、候选对照与独立审核状态。
