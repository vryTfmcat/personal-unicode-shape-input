# 来源范围与综述

## 允许扫描的冷归档来源

字符与符号组合候选仅来自：

1. `90_旧库冷归档/2025Obsidian备份_只读/时间的方向/符号/𓆟`
2. `90_旧库冷归档/2025Obsidian备份_只读/时间的方向/符号/𓆟⊙`
3. `90_旧库冷归档/Unicode原库_迁移前快照/茂ܜ/符号/字符`
4. `90_旧库冷归档/Unicode原库_迁移前快照/茂ܜ/符号/自创语`

词汇候选仅来自：

5. `90_旧库冷归档/Unicode原库_迁移前快照/茂ܜ/词汇`

## 明确排除

- 不扫描 `时间的方向/符号` 中任何未列出的目录或文件。
- 不处理日记、对话、健康、生活或其他个人资料。
- 不移动、复制、改写或删除冷归档中的文件。
- `茂ܜ/符号`的其他内容只能在需要解释某个已提取候选时按需参考，不能自行扩展候选池。

## 理论页的例外

`理论/`中的页面可以按需引用冷归档的图形语、人机协同、字符艺术和符号学资料，用来解释输入法设计问题。这些资料不由构建工具扫描，不会成为字符或词汇候选，也不改变上面的候选来源范围。

## 处理方法

构建工具只枚举上述五个根目录中的 Markdown 文件名，过滤 AppleDouble `._*` 文件和附件；它不读取笔记正文。工具从文件标题提取符号候选，将相同 NFC 字符串合并，并保留所有来源路径。自动提取可能误识别，因此候选需要人工确认后才能成为实体页或 Rime 条目。
