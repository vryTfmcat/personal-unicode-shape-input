# Unicode 键盘标注原型 v0.1

2026-10-18。入口为本目录 `virtual-keyboard.html`。运行已有 `启动键位编辑器.cmd`，在编辑器顶部点击“键盘标注 ↗”。服务默认地址为 `http://127.0.0.1:8765/virtual-keyboard.html`；端口若调整，使用同一编辑器服务下的页面。

## 操作

1. 选择 MK68 Colemak 或 Razer ISO，点击图上的键。
2. 在右侧粘贴字符或键义，点击“应用标注”。例如选择 MK68 顶排 F，填入 `Ⱝ`。原键帽文字可作为角标显示／隐藏。
3. 基础层、Shift 层分别保存；下拉框切换当前编辑层，按实体 Shift 不自动切层。
4. 页面有焦点时，按键事件按物理位置高亮；输入框编辑期间让出按键。选键后点“按实体键校准”可重绑，Esc 取消；重复绑定会移除旧位置的同一事件绑定，可撤销。
5. “恢复原键”清除当前键、当前层标注；“撤销”保留最近 40 次修改，刷新后不保留撤销记录。
6. 草稿自动保存到当前浏览器、当前来源地址的 localStorage；导出 JSON 保存独立文件。不同浏览器或端口不共享草稿，换设备需要导出再导入。导入先检查键盘与外形摘要并显示预览，确认后替换当前键盘的两层标注和事件绑定。
7. 从编辑器入口打开时，可用“取编辑器当前字符”填入当前选中项；仍需点击应用才写入键帽。主编辑器继续选择字符时也会更新当前字符提示。

## 文件职责

- `virtual-keyboard-layouts.js`：2026-10-18 从 Vault `50_实体/_附件/键盘布局/` 两份 `.kle.json` 生成的只读显示快照，68／110 键；KLE 来源仍是外形权威文件，未修改来源。以后更新外形时需重新生成快照；摘要不匹配的旧标注不会直接导入。
- `virtual-keyboard-core.js`：KLE 展开、双矩形轮廓（ISO Enter）、默认事件绑定和方案验证。第一版仅支持内置两套外形，不提供任意 KLE 上传；旋转外形显式拒绝。
- `virtual-keyboard.js`、`.css`、`.html`：独立页面与交互，复用 `fonts/editor-fonts.css`。
- `virtual-keyboard-bridge.js`：编辑器顶部入口及同源、指定窗口的字符传递；不替换现有 `window.keyEditor`。
- `工具/test_virtual_keyboard.cjs`：运行 `node 工具/test_virtual_keyboard.cjs`，从项目工作树执行。

## 验证与边界

本次通过 JavaScript 语法检查、核心自动测试、HTTP 200 与浏览器检查。测试覆盖 KLE 行偏移和宽高重置、68／110 键数量、ISO Enter 轮廓、Colemak F→KeyE、补充平面字符／组合字符串往返、错误方案拒绝。浏览器实际操作覆盖 F→Ⱝ、刷新恢复、Shift 层编辑与撤销、导出后导入预览与确认、实体事件校准、按键事件接收与释放、编辑器当前字符填入。两套外形均已查看。

按下态与失焦清空逻辑已实现；未对两块真实外接键盘逐键验收，也未穷尽浏览器截获的快捷键。Fn／宏键默认未绑定，可能无法捕获。Razer 的小键盘与主键区分别使用 Numpad 系列和普通事件标识。

这一版只显示与标注，不改变 Rime、码本或系统输入，不是跨应用全局键盘监视器。浏览器草稿未接入项目后端保存；需要长期保留时导出文件。没有发布网站、提交 Git 或变更现有码本。
