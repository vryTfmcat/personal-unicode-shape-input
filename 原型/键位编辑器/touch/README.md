# Unicode 触屏拼排 0.2

2026-10-21：增加独立收藏模式、个人中文名称与标签、最近使用、逐码位反查、草稿快照、备份恢复和发布记录。键位空间增加手机 QWERTY 预览和按键行为配置；上方中英切换、Z 左侧模式循环。支持生成 Trime 部署 ZIP；Android 版还可通过一次目录授权更新固定交接目录。完整现行说明见 `原型/安卓app/README.md`。下方 0.1 记录中的“取用盘和试输文本不随布局导出”仍适用于旧布局 JSON；新版完整草稿备份包含收藏资料和最近使用，不包含临时试输文本。

本轮保留三类语义：自由空间只保存拼图位置，手机键盘配置改变显示或按键行为，输入编码修改后续开放。既有收藏输入码仍从源快照只读显示。完整详情改码、编码格位、画布框选分页没有提前实现。

主工程在库外工作树；本目录是原有键位编辑器的触屏界面。统一提供区块、全形、键位空间三个入口。旧编辑器顶部的“触屏拼排”可直接打开。

- 区块浏览：Unicode 17，159,345 个字符、336 个区块；按符号、码位、英文 Unicode 名称、区块码搜索。搜索跨整个字符快照。
- 全形浏览：复用 `data/shape-stage.json` 阶段分桶以及桶内次序，显示“分类待核对”；尚未形成正式四码。不会把机器分类写成人工确认。
- 取用：点字符查看详情，再点“取用到键位空间”。同一码位可以放置多份元素。取用盘长按 0.9 秒移除，已放置元素保留。
- 自由空间：512 × 512 格。拖空白平移、双指缩放、按钮缩放，元素拖动吸附网格。也可以先选元素，再点空格移动。已有元素占用的格子不会被覆盖。
- 实体键盘：复用现有 MK68 / Razer KLE 外形和 ISO Enter 解析。先取用字符，再点键帽标注。外接键盘可高亮对应物理键位；试输开启后，已标注物理键输出字符到应用内文本框。物理位置采用现有原型的默认映射；本界面暂无校准及 Shift 标注层。
- 试输：点击空间元素或标注键帽向应用内文本框加入原始字符，支持复制。没有 Android 系统输入法服务。
- 保存：布局、取用盘、缩放级别保存在本浏览器或 Android 应用的私有本地存储。更换屏幕尺寸后首次进入空间自动居中元素。80 步撤销／重做只在本次页面会话有效。
- 导入导出：独立 `unicode-touch-space-v1` JSON。导入先校验字符身份、碰撞、范围和键盘键位，再显示替换预览；确认后可以撤销。不接受旧版键帽 JSON 或码本 JSON，避免混用格式。
- 字符身份：使用既有码位 ID，不执行 Unicode 归一化，不合并同形异码字符。

布局文件只包含元素和键帽标注；取用盘和试输文本不随布局导出。应用卸载会清除本地存档，保留导出 JSON 才能恢复布局。尚未实现跨设备同步、批量框选、自由尺寸键帽或真实输入法输出。

## 运行和构建

从工程根目录运行 `python 工具/build_touch_data.py` 生成只读字符快照。然后复用原有 `原型/键位编辑器/serve.py` 服务，打开 `/touch/index.html`。`/touch/preview.html` 是 390 像素手机和 820 像素平板的浏览器尺寸预览，不是 Android 模拟器。

Android 工程与 APK 见 `原型/安卓app/README.md`。新界面不使用旧编辑器的保存 API，不改动项目码本、Rime 或原始 KLE。字库是构建时快照，之后修改源数据须重新构建 APK。
