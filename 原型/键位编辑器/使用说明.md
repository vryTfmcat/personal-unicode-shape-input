# Unicode 三模式编辑器 · 第一版

双击 `启动键位编辑器.cmd`，打开本机 `http://127.0.0.1:8765/`。需要 Python 3 与 PyYAML；本机启动器优先使用已具备依赖的运行环境。服务仅绑定本机地址。

全形资料面板中的“四位键位总览”打开 `shape-key-overview.html`。四轮共用 `20261021-connected-stroke-group-full-v1`（v14）：四层键义、代表字与对象、大重码组、覆盖与漏收。每位保留全部26键，包括空键；候选默认全量分层，支持编码、字符、码位及分页。详情中的蓝框仅用于对象定位，精确取形示例另见 Q／D／E-F 核对图。

这是只读独立入口，不替换现行码表、不写人工确认、不发布小狼毫。现行配置继续从原有 `shape-review-profile.json` 读取。总览由 `serve.py` 的只读接口校验固定索引后提供，不复制全量数据。旧服务进程需重新启动才能识别新接口；也可另选空闲端口启动。

2026-10-22：第一轮新增“旧桶整理与 u／v 新用途试验”，第四轮也有同一入口。独立整理 t／u／j／v／b／g 六桶443字，旧第一位、旧编码和10项历史确认未改动。`u`线群42字通过锁定字体九扰动；`v`台阶拼块8字基准匹配，仅1字九扰动稳定，7字单列不稳定。另有4个现有三角形入口补回候选，尚未写码。报告保存在 `数据/三模式/规则库/四键实验/键位试验/20261022-historical-buckets-pilot-v1/`；不是新的全量码表或已接受的新键义。

顶部按钮选择正在编辑的码本；“候选来源”勾选实际查询的模式，可任意组合。点击模式按钮会切到该模式单独查询，随后可继续添加其他来源。浏览器记住选择。

- **区块**：Unicode 17 平面 → 固定区块 → 两位前缀 → 区块专属后两位。全部 56,347 个非汉字字符已生成唯一四码；323 个区块使用 360 个前缀。机器初稿按粗形族与均衡序位分配，局部组名尚待人工核定，不能视作正式字形规则。详情可以改码、确认，区块规则面板可以修改键义、预览前缀调整及受影响字符。不同区块不能共用前缀；一个区块可以有多个前缀。
- **全形**：主形和状态放在前两位。第一版已有 2,761 个粗分类建议，圆形族 `oe` 可跨区块检索。已确认批次通过 paths 保存全部四码路径，第三位查这些路径前缀、四位精确查码；不会忽略多余输入并回退到两码形族。第04、07批仍是试验，不能进入查询。其他字符进入未分类队列，逐字选择主形、状态、参考字体并确认。“规则试验与候选对照”可比较形族、保存细分规则笔记，不自动生成未审核的全形四码。
- **收藏**：每字可以有多个独立 2～4 字母别名。“待选旧码”保留旧人工码、联想码和本浏览器旧补丁，默认停用；勾选启用才进入候选。修改收藏别名不会改变前两套编码。常用收藏标记与输入别名独立；收藏模式还保留双字母感觉、联想图谱和原有笔记、关系。

拖到全形组会形成待核对分类；拖到常用收藏会标记收藏。Unicode 真实区块不随拖动或前缀变更改变。“首批核对”依次打开几何图形、巽他标点、基本拉丁；逐字核对后点击确认即可。普通重建只更新机器基础数据，保留人工码本。

## 中文与读音

中文候选默认关闭，采用锁定的小鹤官方查形数据中 URO 的 8,114 字。另一开关可加入可靠的 296 个扩展字与 `〇`。多音字保留多个有效四码；异常片段 `𬹼 xpv`、`砦 vdv+` 未猜补。`𬹼` 的其他有效码仍可用。其余统一、兼容汉字可研究浏览与自定收藏，不占区块前缀。部首、笔画、注音、标点保持各自区块。

来源为 `https://flypy.cc/ix/ixdata.json`，版本资料日期 2026-09-30，本次锁定读取日期 2026-10-05，SHA256 记录在 `数据/三模式/flypy-source.json`。“检查小鹤来源差异”展示当前上游新增、移除、修改和校验值，保留本次锁定版本。

读音单独放在字符资料中：语言、转写原文、IPA、生成器来源与审核说明。可将音素机的结果作为 IPA 文本记录；编辑器不保存音频。没有独立读音的图形可留空，若读的是名称需注明。

## 保存与发布到小狼毫

编辑后约 0.9 秒自动保存 `数据/三模式/codebooks.json`；图谱继续保存 `数据/联想图谱/association-graph.json`。服务器用版本校验、原子替换与快照保护；浏览器只留未保存的恢复草稿。另一窗口先保存时，旧窗口会收到冲突提示，应导出草稿再重新载入。不同版本的恢复草稿保留为可导出的冲突稿，不自动覆盖项目。

“码本快照”创建恢复点。导出码本保存人工覆盖、收藏、IPA 和试验笔记；完整 TSV 导出各套有效编码。旧草稿可重复导入，迁移标记阻止重复别名。

编辑器保存的是项目草稿。点击“发布到小狼毫”才统一构建五个独立词典，先调用本机 Rime 核心在临时用户目录验证，再备份、同步和重新部署；最后校验本机编译词典的真实候选。发布备份位于 `原型/rime/备份/unicode-modes-日期时间/`，包含旧配置、发布码本和验证清单。失败会恢复本次替换的源文件并尝试重新部署。

首次在小狼毫方案菜单中选择 **Unicode 三模式**（`personal_unicode_modes`）。

- 左 Shift 单按：区块 → 全形 → 收藏 → 三者混合；切换保留正在输入的码并刷新候选。长按只切一次，Shift 组合键不切模式。
- 右 Shift：切 Unicode／英文。
- Ctrl+Shift+1、2、3：分别开关区块、全形、收藏，可形成全部七种非空组合。
- Ctrl+Shift+4：中文；Ctrl+Shift+5：扩展字，中文开启时才生效。
- 空格／数字选字，PageUp／PageDown 或 `-`／`=` 翻页；全形两码的候选完整保留。

混合顺序是收藏 → 区块 → 全形 → 中文。相同字符合并并显示所有来源；字形相同但码位不同的字符保留为不同候选。模式和中文开关独立保存到 Rime 用户目录的 `unicode_modes.preferences.yaml`，重启恢复。

## 个人语言与配音接入（2026-10-08）

整合启动器读取本三模式字库，通过 `window.keyEditor.getSelectedItem()` 与 `unicode-character-selected` 事件挂载个人配音；面板在详情外独立存在，不随详情重画丢失。原型编辑器独立运行时仍不保存音频；个人音素及组合的Markdown由70_unicode维护。语言工作台独立操作表达图结构，不改写联想图谱的意义。

## 字符字体（2026-10-15）

字符卡片、详情和图谱接入 `fonts/editor-fonts.css`。参考 SYMBL 的字体分片思路，使用同源 WOFF2 与精确 `unicode-range`，浏览器只请求当前字符需要的文件；不依赖系统预装字体，也不调用 SYMBL 的字体 CDN。Noto/Gentium 原生轮廓优先，遍黑体覆盖扩展汉字，剩余字符使用已有通用轮廓与 Unifont 回退。

本次实际文件核验：159,345 个数据字符均有非 `.notdef` 映射，761 个字体文件约 29.2 MB（浏览器按需加载，不会首次全部下载）。11 个可见字符样本还核验了非空轮廓，包括埃及象形文字、楔形文字、数学字母以及 CJK 扩展 B/I/H/J。此结果不代表所有组合排版和所有设备都已人工验收，部分回退字体带有像素风格。

复制与 TSV 导出仍使用原始字符；未改码本或字符身份。字体请求失败会提示；未来新增而无字体的字符会显示码位说明。

更换电脑或复制部署时，保留完整 `fonts/`、`font-status.js` 及许可证目录。更新后刷新页面。构建工具为 `工具/build_editor_fonts.py`，字体文件与真实数据交叉核验工具为 `工具/validate_editor_fonts.py`；重新构建需要本机源字体和 `工具/work/editor-fonts/` 中的源分片，详见 `fonts/README.md`。

### 像素字形修正

“有字体映射”只说明字符可显示，不保证轮廓平滑。上一轮 Gurmukhi 有 70 个字符由 Unifont 提供，放大后出现像素阶梯。本轮为整个 80 字区块统一选择 Noto Sans Gurmukhi，并为其他可取得原生轮廓的文字替换回退来源。更新工具为 `工具/promote_editor_outlines.py`；它只替换显示字体，不修改字符、键位或复制内容。校验新增古木基样本的曲线命令检查，避免再次把像素轮廓误当作清晰字体。

## 全形核对版（2026-10-18）

全形模式新增“本轮核对版 · 一至四键”，与小狼毫全形层共用`数据/三模式/全形核对版.json`指定的固定索引。面板展示四层键义；未分配字母不补位。第一位、形族入口及全部成立路径可查询，第三／第四位不作无条件组合。阶段分桶与历史形码可切换查看；核对版不通过拖动改写确认归属，仍可沿用逐字备注。完整TSV追加核对版主桶、主形族、形族入口、取形码及版本列。

核对入口与回退：关闭工程`数据/三模式/全形核对版.json`的enabled字段并同步网页入口后，构建恢复历史形码；若需立即恢复本次部署前配置，使用项目`原型/rime/备份/`中对应发布目录的manifest.json列明文件恢复并重新部署。不要只还原网页镜像造成编辑器／Rime版本不一致。
