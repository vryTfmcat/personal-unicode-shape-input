# Unicode 音型键位编辑器

## 启动

双击 `启动键位编辑器.cmd`。程序只在本机 `127.0.0.1` 临时启动网页服务，并自动打开默认浏览器；关闭命令窗口即可停止。初次读取约 44 MB 的全量数据时可能需要几秒。

## 当前数据

- Unicode 17 全字符表：159,345 个字符。
- 实际前缀页：380 页；“常用字符”另作为收藏视图。
- Kirat Rai 优先使用 `kr`；其他区块也优先使用英文区块名的首字母缩写。
- 一个机器生成的前缀页只服务一个 Unicode 区块；大区块会分配多个相关前缀。每个四码最多 5 个候选。

## 页面行为

- 左侧可以按前缀、区块名或页面名搜索。页面显示字符数，但每次只渲染 400 张字符卡；需要时点击“继续显示”。
- 把字符拖到页面名，会替换前两码并保留原后两码。
- “常用字符”是收藏视图。拖入常用页只添加收藏，不改变原码或实际归属。
- 每一页的“本页形符规则”互相独立。修改规则文字不会自动批量改变已有字符码。
- 点选字符后可编辑完整码、归属、第三键、第四键、收藏和备注。
- 修改自动保存在当前浏览器的 `localStorage`，不会直接改写 Obsidian、Rime 或源 TSV。

## 备份与回写

- “导出 JSON”只导出相对初始数据的修改补丁，文件较小，适合继续编辑。
- “导出 TSV”导出当前完整字符码表，适合审查和回写项目/Rime。
- “导入 JSON”载入 v3 修改补丁；“重置”清空本地修改并恢复项目生成的初始数据。

初始数据由 `工具/build_key_editor_data.py` 从 `数据/Unicode全码表/unicode-17-全字符编码.tsv` 生成。当前数据版本为 v3；旧版浏览器草稿不会覆盖 v3 初始数据。
